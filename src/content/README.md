# Portfolio content

Edit the files in this folder to update your resume portfolio. The app loads these at build time.

| File | Used by |
|------|---------|
| `education.md` | `SRC/Education.tsx` |
| `experience.md` | `SRC/Experience.tsx` |
| `hardSkills.md` | `SRC/HardSkills.tsx` |
| `softSkills.md` | `SRC/SoftSkills.tsx` |
| `aboutMe.md` | `SRC/AboutMe.readme` |
| `hobbies.md` | `SRC/Hobbies.tsx` |
| `github-projects.json` | Source Control panel (GitHub cards) |

Use plain Markdown in `.md` files. Search matches words in all markdown files.
